# Tabapagos

Punto de venta para micronegocios en teléfonos y tabletas Android, con operación local offline, cobros en efectivo/CoDi e impresión térmica Bluetooth.

Stack elegido: **Flutter y Dart**, **Laravel y PHP**, **MySQL para la API**. El tema visual está por definir.

Incluye una landing pública responsive con Vue en el mismo Laravel. La operación del punto de venta se realiza solo en Android: cada dispositivo conserva sus productos y ventas, sin panel web ni sincronización comercial. La API en Hostinger mantiene identidad, cuenta bancaria y datos mínimos de cobros/eventos.

La landing ofrecerá descarga de la APK después de guardar un formulario de datos esenciales en MySQL, junto con una guía de instalación externa. El registro de descarga es independiente del acceso Google dentro de la app.
